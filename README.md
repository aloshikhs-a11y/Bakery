# 🥐 Fresh Bakery

**Oven-Fresh. Online. On time.**

Fresh Bakery is a visually appealing online bakery website created using Canva. It showcases a selection of baked goods, including breads, cookies, croissants, and pastries, through a clean and inviting design.

## ✨ Features

- Attractive bakery-themed homepage
- High-quality visuals of baked goods
- Warm colors and modern typography
- Simple, user-friendly presentation
- Online ordering call-to-action
- Responsive website design provided by the publishing platform

## 🛠️ Built With

- Canva Website Builder

## 🌐 Live Website

[Visit Fresh Bakery](https://supercomputersahmedpur.my.canva.site/dahytkaqlx8)

## 🎯 Project Objective

To create an engaging online presence for a bakery business and present its products through an attractive digital storefront.
